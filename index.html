YouTube History Collector

A personal tool that downloads and stores a local copy of YouTube activity using Google's official Data Portability API.

What it does

The owner chooses the Google account and access duration on Google's consent screen. The tool saves the original exports on the owner's computer and displays watch-history records with their timestamps.

Daily exports are requested while the tool is running, subject to Google's export interval. A recorded timestamp does not establish how long a video was watched.

What this website contains

This website provides information about the tool and its data handling. It does not display watch history, store exported activity, or provide access to the owner's computer. The tool is for personal use, with no public registration.

Read the privacy notice for the data scope, storage and controls, and the personal-use terms for the intended use.
