Privacy notice

YouTube History Collector is a personal tool operated by its owner on their own computer. This notice describes how it handles YouTube activity.

Data accessed and purpose

With the owner's authorization, the tool requests the Google scope dataportability.myactivity.youtube. Google's export can include watch events, video and channel information, timestamps, searches, visits, advertising activity and export metadata.

The purpose is to preserve, view and review a personal activity archive. Only watch events are currently indexed as watch history; the original export may contain the other activity types. The tool does not measure attention or exact playback duration.

Storage and credentials

Downloaded exports, original activity files, a local index and import receipts are stored on the owner's computer. The OAuth client secret and access and refresh tokens are stored in macOS Keychain. The application does not request or store the owner's Google password.

Use and sharing

The tool uses the data for the owner's personal archive. It does not sell it, use it for advertising, or upload it to this information website. It makes no AI model requests. The owner can separately choose other tools to inspect or analyze saved records; those tools have their own permissions, settings and data terms.

The tool contacts Google to authorize access, request exports and download them. Any hosting provider used for this information website may process ordinary website access logs under that provider's policies; this website contains no exported activity and no embedded analytics code.

Retention and controls

Local source copies are retained until the owner deletes them. Pausing updates or revoking Google access stops new collection but does not delete existing local records. The owner can pause daily updates in the application, revoke the application's access in their Google Account, and delete the local archive using their computer's file controls.

Google access is time-limited. The selected access period and Google's applicable restrictions determine when renewed authorization is needed.

Contact and changes

For questions about this personal application, contact the app owner using the support email shown on Google's consent screen. This notice should be reviewed when the application's data handling changes.
